iKontent SNS Analytics プライバシーポリシー

運営者: iKontent
最終更新日: 2026年10月8日

「iKontent SNS Analytics」（以下「本ツール」）は、iKontent が自ら運営する SNS アカウントの数値を集計して投稿の改善に役立て、iKontent 自身の動画を YouTube に予約投稿するための社内用ツールです。一般の方に向けて提供するものではなく、 iKontent 以外のアカウントとの連携は受け付けていません。

1. 取得する情報

本ツールは、iKontent が運営する次のアカウントとファイルについて、各サービスの公式 API から情報を取得します。

  • YouTube（YouTube Data API・YouTube Analytics API・YouTube Reporting API）: チャンネルの登録者数、動画のタイトル・公開日時・長さ、再生回数・総再生時間・高評価・コメント数・共有数・登録者の増減、インプレッション数とクリック率などの集計値
  • Instagram（Instagram API）: 投稿の種類・投稿日時・キャプション、リーチ・閲覧数・いいね・保存・シェアなどの集計値
  • Google ドライブ（Google Drive API）: iKontent が指定した1つのフォルダにある、投稿予定表（公開日時・タイトル・説明・タグ）と、投稿する動画ファイル

これらはアカウント全体、または投稿・動画ごとの集計値と iKontent 自身の投稿予定で、視聴者・閲覧者一人ひとりを特定できる情報は含みません。

本ツールが使う Google の権限は次のとおりで、それぞれ別の認証情報に分けて管理しています。

  • 数値の集計: 読み取り専用（youtube.readonly / yt-analytics.readonly）
  • 予約投稿: 動画のアップロードのみ（youtube.upload）。既存の動画の編集・削除はできません
  • Google ドライブ: 共有した1つのフォルダの読み取りのみ

2. 利用目的

取得した情報は、iKontent の投稿内容の振り返りと改善（週次レポートの作成と分析）と、iKontent 自身の動画の予約投稿のためだけに使います。広告の配信など、ほかの目的には使いません。

3. 保存と管理

  • 取得した集計値と週次レポートは、iKontent が管理する非公開の GitHub リポジトリに保存します。
  • 予約投稿のために Google ドライブから読み込んだ動画ファイルは、YouTube へのアップロードの間だけ一時的に保持し、終了後に削除します。投稿の記録（公開日時・タイトル・動画 ID）は上記のリポジトリに保存します。
  • API の認証情報（アクセストークン等）は GitHub の暗号化された保管領域（Secrets）に保存し、リポジトリのファイルやログには記録しません。

4. 第三者への提供と外部サービスの利用

取得した情報を第三者に販売・提供することはありません。ただし、本ツールの運用のために次のサービスを利用しており、その範囲で各社のサービス上で処理されます。

  • GitHub（データの保存と、収集・レポート作成・予約投稿の自動実行）
  • Anthropic の Claude（週次レポートの分析の補助）

本ツールは YouTube API サービスを使用しています。本ツールを通じた YouTube の利用には YouTube 利用規約が、Google による情報の取り扱いには Google プライバシーポリシーが適用されます。

5. 連携の解除とデータの削除

YouTube・Google ドライブとの連携は、Google アカウントの「サードパーティ製のアプリとサービス」（https://myaccount.google.com/permissions）からいつでも解除できます。Google ドライブは、フォルダの共有を解除することでも停止できます。連携が解除された場合、保存済みの YouTube のデータは7日以内に削除します。そのほかのデータの削除をご希望の場合は、下記の連絡先までご連絡ください。

6. 本ポリシーの変更

本ツールの機能の変更に伴い、本ポリシーの内容を変更する場合があります。変更した場合は、本ページの「最終更新日」を更新してお知らせします。

7. お問い合わせ

本ポリシーに関するご質問は、以下の連絡先までお願いいたします。

iKontent SNS Analytics Privacy Policy

Operator: iKontent
Last updated: October 8, 2026

The Japanese version above is the authoritative text. This English translation is provided for convenience.

"iKontent SNS Analytics" ("the Tool") is an internal tool that aggregates statistics from social media accounts operated by iKontent itself in order to improve its posts, and schedules uploads of iKontent's own videos to YouTube. It is not offered to the public, and it does not connect to any accounts other than those operated by iKontent.

1. Information We Collect

The Tool retrieves information through the official APIs of each service for the following accounts and files operated by iKontent:

  • YouTube (YouTube Data API, YouTube Analytics API, YouTube Reporting API): aggregated statistics such as subscriber count, video titles, publish times and durations, views, watch time, likes, comments, shares, subscribers gained and lost, impressions, and click-through rate
  • Instagram (Instagram API): post type, post time and caption, and aggregated statistics such as reach, views, likes, saves and shares
  • Google Drive (Google Drive API): the posting schedule (publish time, title, description, tags) and the video files in one folder designated by iKontent

These are aggregated values for the whole account or for each post or video and iKontent's own posting schedule, and they contain no information that identifies individual viewers.

The Tool uses the following Google permissions, each managed with separate credentials:

  • Statistics: read-only (youtube.readonly / yt-analytics.readonly)
  • Scheduled uploads: uploading videos only (youtube.upload). It cannot edit or delete existing videos
  • Google Drive: read-only access to the one shared folder

2. How We Use Information

The information is used only to review and improve iKontent's own posts (creating and analyzing weekly reports) and to schedule uploads of iKontent's own videos. It is not used for advertising or any other purpose.

3. Storage

  • Aggregated statistics and weekly reports are stored in a private GitHub repository managed by iKontent.
  • Video files read from Google Drive for scheduled uploads are kept only temporarily during the upload and are deleted afterwards. A log of uploads (publish time, title, video ID) is stored in the repository above.
  • API credentials (such as access tokens) are stored in GitHub's encrypted Secrets and are never written to repository files or logs.

4. Sharing and Service Providers

We do not sell or provide the information to third parties. The Tool relies on the following services, and the information is processed on them only to the extent needed to run the Tool:

  • GitHub (data storage and automated collection, reporting and scheduled uploads)
  • Anthropic's Claude (assistance in analyzing the weekly reports)

The Tool uses YouTube API Services. Use of YouTube through the Tool is subject to the YouTube Terms of Service, and Google's handling of information is subject to the Google Privacy Policy.

5. Revoking Access and Deleting Data

Access to YouTube and Google Drive can be revoked at any time from "Third-party apps & services" in your Google Account (https://myaccount.google.com/permissions). Access to Google Drive can also be stopped by unsharing the folder. If access is revoked, we delete the stored YouTube data within 7 days. To request deletion of other data, please contact us at the address below.

6. Changes to This Policy

We may update this policy when the Tool's features change. When we do, we will update the "Last updated" date on this page.

7. Contact

iKontent.dev@gmail.com
