iKontent SNS Analytics 利用規約

運営者: iKontent
制定日: 2026年10月10日

この利用規約（以下「本規約」）は、iKontent が運営する「iKontent SNS Analytics」（以下「本ツール」）の利用条件を定めるものです。

1. 本ツールについて

本ツールは、iKontent が自ら運営する SNS アカウントの数値を集計して投稿の改善に役立て、iKontent 自身の動画を YouTube に予約投稿するための社内用ツールです。 一般の方に向けて提供するものではありません。本ツールを利用できるのは、iKontent と、iKontent が運営する YouTube チャンネルの所有者（以下「利用者」）だけです。

2. YouTube API サービスの利用

本ツールは YouTube API サービスを使用しています。本ツールを利用することにより、利用者は YouTube 利用規約に従うことに同意したものとします。 Google による情報の取り扱いには Google プライバシーポリシーが適用されます。 本ツールによる情報の取り扱いは、iKontent SNS Analytics プライバシーポリシーに定めます。

3. 本ツールの機能

  • iKontent の YouTube チャンネルへの動画の予約投稿（動画のアップロードのみ。既存の動画の編集・削除は行いません）
  • iKontent の YouTube チャンネル・Instagram アカウントの数値の読み取りと、非公開の週次レポートの作成

4. 利用者の責任

  • 本ツールで投稿する動画は、iKontent が権利を持つもの（iKontent 自身のアプリの映像と自作の音楽など）に限ります。
  • 投稿する動画とその説明は、YouTube 利用規約と YouTube のコミュニティガイドラインに従うものとします。
  • 予約投稿された動画は、公開前に YouTube Studio で確認・編集・削除できます。

5. 連携の解除

利用者は、Google アカウントの「サードパーティ製のアプリとサービス」（https://myaccount.google.com/permissions）から、本ツールと YouTube の連携をいつでも解除できます。 解除した場合のデータの扱いは、プライバシーポリシーの「連携の解除とデータの削除」に定めます。

6. 免責

本ツールは現状のまま提供します。YouTube その他のサービスの仕様変更などにより、本ツールの機能の全部または一部が利用できなくなる場合があります。

7. 本規約の変更

本ツールの機能の変更に伴い、本規約の内容を変更する場合があります。変更した場合は、本ページに日付を記載してお知らせします。
